# Mari 中文补丁

当前仅提供 **Inno Setup 安装器**，文件名为 `MariChineseInstaller.exe`。安装、更新、迁移及卸载说明见 [安装指南](docs/installer.md)。卸载请使用 Windows“已安装的应用”，不再使用旧安装器。

这是一套给 **Foundry Mari** 用的中文界面汉化补丁。它能让你在画图（贴图绘制）时看到中文的菜单、按钮、选项和提示，而不会改动你的工程数据或 Mari 原始文件。

**适用范围**：使用完整 Qt 5 x64 运行时的 Windows 版 Mari；不维护具体 Mari 版本白名单。Mari 4、5、6、7（含 7.1 / 7.5）为已覆盖版本。

---

## 它能做什么

- **界面变成中文**：菜单栏、工具栏、面板、下拉框、设置项等到处都用中文显示。
- **不碰你的工程**：翻译只发生在"画出来"的那一层，英文原文始终留在数据里。你的 `.mri` / `.mra` / `.mnc` 工程文件不会被写入任何中文。
- **不覆盖原程序**：补丁通过一个独立启动器运行，Mari 本体文件一个都不替换。想恢复英文，一键搞定。
- **高分屏 / 4K 友好**：内置"4K 屏优化"，解决高 DPI 屏幕下 3D 画面缩在角落、模糊的问题。
- **一键切换中英**：运行时可随时在中英文之间切换，不用重装。
- **保留文件关联**：可接管已验证的工程打开命令；卸载按归属恢复，不覆盖后续外部修改。

## 怎么安装

1. 先确认你已经装好 Mari（任选一个受支持版本）。
2. 双击运行 **`MariChineseInstaller.exe`**（安装程序）。
3. 「安装位置」会自动帮你找到 Mari 的 `Bundle\bin` 目录；如果不对，点右侧的 **浏览…** 手动选择。
4. **启用 4K 屏优化**默认不勾选。只有 4K / 高 DPI 屏幕才需要勾选，缩放系数一般用默认的 `1.75` 就行，也可以在 `1.0`–`3.0` 之间调整。
5. 按向导点击“安装”。
6. 装好后，通过桌面或开始菜单里的 **“Mari 中文版”** 快捷方式启动 Mari。

> **安装位置填什么？** 一定要选到 Mari 程序所在的那一层 `Bundle\bin` 目录（里面能看到 `Mari7.5v1.exe` 这类文件）。填错会提示重新选择程序目录。

## 怎么用

### 启动

用桌面或开始菜单里的 **“Mari 中文版”** 快捷方式启动，功能就跟原版一样，只是界面是中文。选择工程关联选项且当前默认处理器受支持时，双击 `.mri`、`.mra`、`.mnc` 可通过中文启动器打开。

### 切换中英文

- 在菜单栏找到 **“中/英”** 这一项。
- **左键单击**它：立即在中英文之间切换。
- **中键单击**（鼠标滚轮按下）它：打开快捷键设置弹窗，点击录入按钮后按新键，再点“确定”保存，下次启动继续使用。默认 `F3`；`Esc` 取消录入，取消或关闭窗口不保存，“重置”也需要点击“确定”提交。
- 快捷键独立保存在 `%LOCALAPPDATA%\MariChinese\hotkeys.json`，不改 DPI 的 `settings.ini` 或宿主快捷键。支持单键，不支持组合键；建议使用不与宿主操作冲突的功能键。

> 切换只影响界面显示，不会改动或自动保存工程数据；仅在快捷键设置中点击“确定”时保存插件自己的按键配置。

### 4K 屏优化

安装时勾选了"启用 4K 屏优化"的话，补丁会自动按你的屏幕做缩放修正，让 3D 视口不再缩在角落、也不模糊。如果你觉得界面偏大或偏小，可以改缩放系数，之后重新启动 Mari 生效。

也可以直接编辑 `ChineseLauncher\settings.ini` 文件：

```ini
[Dpi]
Enabled=0
ScaleFactor=1.75

[Hooks]
FallbackPolling=0
```

`Enabled` 默认是 `0`（关闭），改成 `1` 开启 4K 优化；`ScaleFactor` 填 `1.0`–`3.0` 之间的数字即可。

`FallbackPolling` 默认是 `0`（关闭）。正常情况下由 Qt 生命周期事件捕获晚创建控件；只有特定 Mari 版本或插件仍会漏掉控件时，才改成 `1` 开启每 2 秒一次的兼容性兜底扫描。

## 怎么卸载

保存工程并退出 Mari，在 Windows“已安装的应用”中卸载“Mari 中文补丁”。用户修改过的词典及额外文件保留，补丁生成的备份和快捷键配置清除；工程关联仅恢复仍属于补丁的部分。

## 常见问题

### 装了之后，双击工程文件还是用原版打开？
用桌面或开始菜单的 **“Mari 中文版”** 快捷方式启动即可；文件关联一般安装时就配好了。

### 界面有的地方还是英文？
补丁是显示层汉化，基于一份词条词典匹配。极少数动态拼接、或不在词典里的文本（比如插件生成的）可能保持英文。有可见控件上下文的节点文字、下拉列表委托支持图像显示缓存；无此上下文的离屏图像及导出绘制保留原文。无法归属控件的界面缓存仍可能保持英文。你可以用快捷键 `Shift + ~`（波浪线，Esc 下方那个键）采集未翻译的词条，会保存到桌面的 `Mari_untranslated_zh.json`，方便后续补充。

### 4K 屏优化有什么用？不开行不行？
如果你用的是普通 1080p 屏，可以不开。如果屏幕是 4K / 高 DPI，建议开启，否则 3D 视口可能变小或发虚。

### 会损坏我的工程或原 Mari 吗？
不会。补丁全程不修改 Mari 本体文件和工程数据，只做显示层翻译。拆掉后一切还原。

## 开发者：从源码构建

需要 Visual Studio 2022（含 C++ 桌面开发）和一个 Qt 5 x64 MSVC SDK。运行：

```
source\build.bat
```

正式发布时应把 `QT5_BASELINE` 指向 Qt 5.6.1 x64 MSVC SDK，以验证最低 ABI 兼容；未设置时脚本会用本机现有 Qt 5 SDK 构建，但那只用于本地开发，不能替代最低版本验证。构建完成后，单文件发布包位于：

```
dist\MariChineseInstaller.exe
```

DPI 修复核心代码在 `source\dpi_hook.cpp`，与汉化模块一起链接进 `MariChineseHook.dll`。启动器只注入一次；DPI 未启用时不会安装相关事件过滤器或虚表钩子。

词典的精确、归一化和省略文本匹配集中在 `source\translation_lookup.cpp`。修改匹配规则后，可用 Qt 5 SDK 运行回归检查：

```
scripts\test_translation_lookup.bat "C:\path\to\Qt\5.6.1\msvc2015_64"
scripts\test_hotkey_settings.bat "C:\path\to\Qt\5.6.1\msvc2015_64" 5
```
