# Mari 中文补丁

面向 Mari 4–7 的纯显示层中文补丁。补丁通过独立启动器加载，不修改 Mari 原始文件和工程数据。当前实机回归环境为 Mari 7.1v1；旧版本兼容采用 Qt 5.6 最低接口与运行时能力检测，不按 Mari 版本号写死。

## 安装

1. 运行 `MariChineseInstaller.exe`。
2. 确认 Mari 的 `Bundle\\bin` 安装目录。
3. 按需要启用“4K 屏优化”并设置缩放系数，然后点击“安装汉化”。
4. 安装完成后，通过桌面或开始菜单中的“**Mari 中文版**”启动。

安装器会在 Mari 可执行文件目录内创建 `ChineseLauncher`，其中包含启动器、Hook DLL、词典和设置文件。原软件文件不会被替换。

安装后，`.mri`、`.mra`、`.mnc` 文件会通过汉化启动器打开。安装器会保存安装前的用户文件关联，拆卸汉化时自动恢复。

## 4K 屏优化

- 安装时默认启用，默认缩放系数为 `1.75`。
- 可输入 `1.0` 到 `3.0` 之间的数值。
- 该选项使用 Qt 原生缩放，并对 Mari 画布安装经过独立实验验证的 DPR 和帧缓冲尺寸修正。
- 不需要时可取消勾选，此时不会安装 DPI Hook，也不会设置 Qt 缩放环境变量。

安装后也可编辑 `ChineseLauncher\\settings.ini`：

```ini
[Dpi]
Enabled=1
ScaleFactor=1.75
```

修改后重新启动 Mari 即可生效。

## 中英文切换

补丁支持运行时切换中英文：左键单击菜单栏的“中/英”进行切换，中键单击可打开快捷键设置弹窗。翻译只发生在显示层，不会把中文写入 Mari 工程数据。

## 拆卸

重新运行安装器，选择相同的 Mari 目录，然后点击“拆卸汉化”。安装器会删除 `ChineseLauncher` 和补丁创建的快捷方式，并恢复安装前的 Mari 文件关联。如果用户在安装后自行更换了默认程序，拆卸时不会覆盖该选择。

## 从源码构建

运行 `source\\build.bat`。正式发布时应将 `QT5_BASELINE` 指向 Qt 5.6.1 x64 MSVC SDK；未设置时脚本会使用现有 Qt 5 SDK进行本机开发构建，但这不能替代最低版本 ABI 验证。构建完成后，单文件发布包位于：

`dist\\MariChineseInstaller.exe`

DPI 独立实验仍保留在 `experiments\\dpi_vtable`，正式汉化复用同一份 DPI 核心代码，但不会启用实验日志。
