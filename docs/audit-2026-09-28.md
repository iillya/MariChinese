## 本轮修复

- 真实发布 DLL 的加载测试发现：Qt 5.6.1 中，从没有 Qt 事件循环的 Win32 工作线程调用 `QTimer::singleShot` 未完成 GUI 初始化。改用移动到 GUI 线程的临时 QObject 接收 `postEvent`，仍由 GUI 线程安装全部 Hook。Qt 5.6.1、5.15.2 均实测初始化成功。
- 切换语言时，宿主的同步 `FontChange` 回调可能销毁快照内的其他控件。改用弱指针快照，并在布局回调后再次检查存活状态。
- 恢复三个带返回边界矩形的 `drawText` 重载在 QWidget 上的翻译。返回矩形对应实际中文；图像等导出设备仍保留源文字和源矩形。这避免因调用方需要文字边界而漏汉化。
- 固定注入 DLL 的进程期生命周期，避免 Qt 回调和 IAT/虚表指向已卸载代码。
- 两个测试脚本明确 `/Fo` 输出目录，避免测试对象文件散落项目根目录；构建脚本检查编译环境初始化失败。
- 字体 Hook ABI 注释改为项目中性说明。保留全部既有宽度、尺寸、边界、省略、节点和自定义控件显示路径。
